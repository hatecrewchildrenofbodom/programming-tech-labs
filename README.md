# 🍄 Составление отчётов для лабораторных по ТП

В данном репозитории будут публиковаться материалы для создания отчётов по лабораторным по ТП по мере их выполнения.

## 📖 Короткий гайд по структуре репозитория

В репозитории находятся следующие каталоги:  
- ***guides***  
Содержит методические указания к лабораторным работам в формате .pdf. Обновляется по мере получения новых методичек от преподавателей.  
- ***labs***  
Содержит материалы по выполненным лабораторным (скриншоты, код, и т. д.). Обновляется по мере выполнения работ. Номера подкатологов соответствует номерам работ.

Каждый пронумерованный каталог из *labs* содержит следующие подкаталоги:  
- ***screenshots*** — Скриншоты процесса выполнения работы  
- ***code*** — Код выполненных заданиЙ 

### ❗️*Важно:*
> В каталогах с материалами может содержится файл *info.txt*. В данном файле содержится информация о том, как должны быть использованы файлы каталога в отчёте.

## 👾 FAQ по C#

### ❓Как установить C# в VSCode?
> Необходимо установить .NET SDK с [официального сайта](https://dotnet.microsoft.com/en-us/download).  
Затем установить [официальное расширение](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.vscode-dotnet-runtime) от Microsoft и перезапустить VSCode.

***🚫ВНИМАНИЕ, РЕКОМЕНДУЕТСЯ УСТАНАВЛИВАТЬ .NET НЕ НИЖЕ 10.0!🚫***

### ❓Как запустить программу на C#?
#### Способ 1 (оптимально для многофайлового проекта)
>Просто запустить нужный файл кнопкой ***Run project, associated with this file***.  

#### Способ 2 (оптимально для одного файла)
>Необходимо открыть в VSCode папку, где находится нужный исходный файл с расширением *.cs*. Для этого необходимо выполнить: *File* &rarr; *Open Folder*, после чего выбрать необходимую папку.  
Далее нужно открыть терминал (*Terminal* &rarr; *New Terminal* или ***Ctrl+Shift+\`***), в котором необходио выполнить следующую команду:  
`dotnet run <your_file.cs>`  
.NET скомпилирует и выполнит Ваш файл.
